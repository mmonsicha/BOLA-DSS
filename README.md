# BOLA DSS UI Only

DSS-only prototype project for BOLA Dashboard, LINE OA, Contacts, and Segments.

## Goals

- No Tailwind
- No backend API
- Mock data only
- DSS runtime components + `@uxuissk/design-system/styles.css`

## Run

```bash
npm install
npm run dev
```

## Preview

```bash
npm run preview
```

## Notes

- This project intentionally contains no Tailwind and no backend API integration.
- The UI is rebuilt with `@uxuissk/design-system` and `@uxuissk/design-system/styles.css`.
- State is mocked locally for prototype flows only.
